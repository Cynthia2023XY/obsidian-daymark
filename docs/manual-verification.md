# Daylane 原生 Obsidian 人工验收

本清单区分自动化 DOM／业务测试与真实 Obsidian 运行验证；未勾选的项不能声称已通过。

- [ ] 在独立测试 Vault 安装发行目录，插件正常启用且无控制台异常。
- [ ] 完全关闭并重启 Obsidian，已有事项首次加载不漏显示。
- [ ] 新建、编辑、完成、取消、重新打开、改期与回收站删除均正常。
- [ ] 直接修改、重命名、删除事项文件，日历同步刷新；正文与未知属性保留。
- [ ] 固定日程跨周、跨月、跨年条带正确，边界包含结束日。
- [ ] 大屏最大化、独立弹出窗口、侧栏以及窄窗口都可读、可操作。
- [ ] 展示模式与 interactive: false 不显示修改入口。
- [ ] 阅读视图与实时预览渲染 daylane 代码块，错误配置只影响对应代码块。
- [ ] 同时打开多个日历，月份独立，事项修改同步，关闭再打开不重复监听。
- [ ] 放假与调休上班标记正确，未收录年度明确提示。
- [ ] 在测试 Vault 启用自动流转，午夜／重新启动／返回前台时正确处理；固定日程不动。
- [ ] 工作日模式在缺失年度不写入；默认关闭与单条覆盖均符合设置。
- [ ] 流转后截止日期与正文保留，重启后可撤回；外部修改后撤回跳过。
- [ ] 手动导入旧事项先预览再复制，不改源文件、不重复导入。
- [ ] 自定义番茄钟时长、暂停、继续、切换与重置正常，多个面板一致。
- [ ] 后台等待与电脑睡眠恢复后时间正确，到时仅提示一次。
- [ ] 关闭番茄钟面板继续计时，禁用插件后停止计时并清理资源。
- [ ] 可选提示音正常；音频不可用时文字通知仍然可用。
- [ ] 最低 Obsidian 1.7.2 真实安装验证；若不兼容，调整最低版本。
- [ ] 移动端真实设备验证通过后才将 isDesktopOnly 改为 false。

建议使用复制的测试事项验证自动流转，确认行为后再在日常 Vault 启用。
