# Daymark 0.2.1 原生 Obsidian 验收

浏览器预览与自动化测试不能替代真实宿主。建议先在测试库验证，安装时保留 data.json。

1. 启用插件后左栏自动展开，主编辑器继续保留焦点；重新加载不会生成重复日历。
2. 在侧栏、独立页、代码块比较参考图样式；验证宽侧栏和窄侧栏、浅色与深色主题、休／班角标、蓝色今天和选中日期、红点、粉色日期标题。
3. 添加“测试b”，只出现名称输入框，Enter 创建；核对文件名测试b.md、四项 YAML 和 ## 测试b。已有普通文件或目录同名时创建测试b 1.md。
4. 勾选／取消完成、点击标题、外部修改 YAML、更名文件、更名所属文件夹；事项应及时更新且不丢失。
5. 右击事项，测试自然日、工作日、自选日期和入箱；保留原累计计数。待办箱底部入口、命令入口及返回日历均可用。
6. 设置最大次数 5。过期 open 事项分别从计数 4、5 测试：前者改期并增至 5，后者仅移除日期且仍是 5；completed、未来日期和无日期不被自动移动。跨夜、休眠恢复及启动补偿各验证一次，不能重复计数。
7. 节假日中的工作日顺延应跳过休息日、接受调休上班日；未覆盖年份应提示，不猜测排班。
8. 目录限制默认生效；关闭后库根目录带标记文档可识别，无标记的普通文档不会成为事项。观察大库首次扫描和连续编辑性能。
9. 默认删除使用 Obsidian 回收机制；实验性删除仅移除四项专属属性，正文和其他 YAML 保留。
10. 旧格式预览期间不写文件；跨日／取消项先明确处理方式。确认完整 JSON 备份、正文和笔记元信息保留、规范命名后的内部链接正常。预览后改原文应被拒绝；无效文件不得阻塞其他事项。
11. 命令面板仅 5 条；批量移到今天不影响未来事项与待办箱，完成今日只处理今日事项。
12. 设置页两张卡片；独立番茄钟 25/5 默认值、自定义 37 分钟、暂停／继续／重置、提示音开关、到时只响一次。核对音频首次用户交互后可播放及休眠恢复计时。
13. interactive: false 的代码块不能完成、删除、创建、改期；正文渲染销毁后无残留订阅。
