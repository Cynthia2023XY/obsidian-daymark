## 2026-10-12 侧栏宿主样式修复

本地目录已更名为 obsidian-daymark。Obsidian 通用按钮背景覆盖原低优先级类选择器，导致日期格、导航和事项标题呈现灰色底块。已给日历按钮加根容器与元素限定，提高优先级；选中日保留蓝底，完成项保留删除线，修复原生复选框伪元素冲突。背景、普通文字和分隔线使用宿主主题，不固定深色背景。日历不再展示“事项提示与旧数据迁移”区域；旧数据迁移入口仅保留在设置页。

56 项测试、中文注释检查、类型检查、构建通过。测试库已重新部署，保留 data.json。通过真实宿主 computed style 核验：未选日期、事项标题与删除按钮背景均为透明，选中日 rgb(66,133,223)，月历背景透明并沿用主题，已完成标题保留 line-through，日历诊断区已移除。完整宿主视觉截图未完成；下面是共用组件的浏览器预览，不能代替全主题视觉验收。

## 左侧栏默认位置

默认加载、日历图标、打开侧栏命令及待办箱入口改为左侧栏。旧右侧紧凑日历在左侧成功创建后关闭，独立大屏保留；自动展开左栏不调用 revealLeaf，以保留编辑焦点。57 项测试通过，包含旧右侧日历迁移、主视图保留和重复打开复用；注释检查、类型检查及打包通过。

侧栏位置进一步修正：使用 getLeftLeaf(false) 将日历加入文件列表所在的主标签组，避免 split=true 新建左下分区。以父标签组判断复用，旧左下日历也会迁移。58 项测试通过；真实测试库确认左侧仅一组，file-explorer、search、bookmarks、daylane-calendar 共用同组。
