# Daylane: Chinese Holiday Calendar

中国节假日与重要事项日历：用 Markdown 保存事项，在大屏或笔记内查看排期，按配置顺延未完成待办，并使用独立的自定义番茄钟。

这是从零实现的独立插件。Calendar Plus 启发了重要事项与内嵌日历的使用需求；本项目不继承其周期笔记、统计或日历组件实现，也没有与该项目的官方维护关系。

## 功能

- 大屏六周月历与侧栏日历，支持项目、状态筛选以及展示模式。
- 单日待办和跨日固定事项，事项对应普通 Markdown 笔记。
- 内置中国大陆 2025、2026 年国务院公布的放假与调休上班安排，完全离线使用。
- 未完成待办自动顺延：默认关闭，支持单条覆盖、自然日或工作日规则，以及撤回最近批次。
- `daylane` 代码块渲染，多个日历共享事项但独立选择月份。
- 独立番茄钟：自定义专注与休息时长，暂停、继续、重置、本地到时提示。
- 手动复制导入 Calendar Plus 重要事项，保留源文件。

## 本地安装

本项目尚未提交或上架官方社区目录。

1. 安装 Node.js 22 或更高版本，执行 `npm ci`、`npm run package`。
2. 将 `dist/daylane` 中的 `main.js`、`manifest.json`、`styles.css` 与 `LICENSE` 复制到目标 Vault 的 `.obsidian/plugins/daylane/`。
3. 在 Obsidian 的第三方插件设置中启用 Daylane。

首版 manifest 声明桌面专用；移动端需要完成真实设备验证后再调整兼容声明。插件使用公开 Obsidian API，最低版本按公开 API 的引入版本设为 1.7.2，但该最低版本尚需实际安装验证。

## 事项与排期

运行“打开大屏日历”命令，或者点击侧边栏日历图标。可将页签拖到独立窗口用于共享屏幕。点击日期选择当天，双击日期或点击新建按钮创建事项；点击事项编辑，详情中可打开笔记。

事项默认存储于 `Daylane/Items/创建年份/`。日期与标题修改不移动文件，正文和未知属性保持原有内容。修改设置中的事项目录只改变索引范围，不搬动文件。

- **待办**：计划日期可以顺延，截止日期保持不变；超过截止日期仍会显示逾期。
- **固定日程**：开始日期到结束日期都包含在排期中，不参与待办自动流转。
- **完成／取消**：停止自动流转，可重新打开。

所有视图以 Markdown 为事实来源。直接修改属性后会刷新日历；结构无效、读取失败或重复 ID 会显示问题，不默默覆盖文件。可通过“重新扫描事项文件”命令重试索引。

## 待办流转

全局开关默认关闭；每条待办支持跟随全局、自动流转、不流转。

自然日模式将计划日期早于今天的未完成待办移到今天。工作日模式移到今天或下一个已确认的工作日，正确考虑调休上班。关闭应用时没有后台进程，下一次启动补处理离线期间的待办；不会提前挪走今天尚未结束的待办。

缺少年度正式节假日数据时工作日自动流转会暂缓，用户可手动改期或切换自然日模式。未完成但不自动顺延的事项保留在“此前未完成”列表。

“撤回最近一次流转”恢复计划日期、流转次数和之前的流转痕迹，不改变正文或截止日期。文件在流转后发生外部编辑、改期或完成时跳过并提示。自动流转不是编辑器操作，不保证可通过 Ctrl+Z 恢复。

恢复意图在文件写入前保存，完整文件摘要在写入后保存。若应用在两步之间意外退出，缺少安全摘要的项不会自动撤回；根据 `lastBatch` 与事项属性可手动核对恢复。这是当前崩溃恢复边界，不是跨设备事务。

## 笔记内嵌日历

````markdown
```daylane
month: 2026-10
project: 基金营销
show-holidays: true
show-completed: false
interactive: true
```
````

`month` 可用 `current`；`project` 可省略。其余字段为真正的 YAML 布尔值。`interactive: false` 隐藏修改入口，但不构成文件权限控制。翻月不会改写代码块配置。阅读视图和实时预览按 Obsidian 的代码块生命周期挂载；源码模式显示原代码。

新插件不注册 `calendar-plus`，避免和旧插件冲突。

## 番茄钟

运行“打开独立番茄钟”。默认专注 25 分钟、休息 5 分钟，可在设置中改为 1—240 的整数分钟，也可在面板临时指定本轮时长。

开始、暂停、继续、重置不改变任何事项。模式切换会放弃当前轮。到时手动开始下一阶段，不自动循环。关闭面板不停止计时；关闭 Obsidian、禁用或重载插件则停止本轮，下次打开为空闲状态。

计时依据截止时间，后台延迟或电脑睡眠后返回会补偿剩余时间，完成通知只触发一次。应用被挂起或关闭时不能保证准时提醒。提示音在本地生成，无网络请求；不可用时仍有文字通知。

## 中国正式节假日来源

- [2025 年国务院办公厅公告](https://www.gov.cn/zhengce/zhengceku/202411/content_6986383.htm)，落款 2024-11-12。
- [2026 年国务院办公厅公告](https://www.gov.cn/zhengce/zhengceku/202511/content_7047091.htm)，落款 2025-11-04。

内置数据随插件发行更新；没有在线自动获取机制。未覆盖年份只显示普通星期信息，并明确提示正式安排未收录。安排用于中国大陆，不包含港澳台各自的假期制度。

## 开发与验证

```sh
npm ci
npm run typecheck
npm run test:run
npm run test:coverage
npm run build
npm run package
```

`npm run dev` 只监视插件源码并重新构建，不启动 HTTP 开发服务。核心日期、文件竞态、流转恢复、迁移、计时与 DOM 交互有自动化测试。原生 Obsidian 的实际视图、安装、弹出窗口、声音与最低版本验证见 [人工验收清单](docs/manual-verification.md)。

已完成检查与验证边界见 [开发验证报告](docs/verification-report.md)。浏览器视觉预览可通过 `npm run preview:build` 生成到 `dist/preview/`，使用本地 HTTP 服务打开；预览只在内存保存演示事项。

项目独立初始化了本地 Git 仓库，当前没有配置远程仓库。技术方案见 [技术方案](docs/technical-plan.md)。

## 隐私与许可证

事项和配置只写入当前 Vault；运行时不联网，不采集遥测，不需要账户，不读取 Vault 外文件。事项通过用户自己的 Vault 同步方案共享，插件不提供多人实时编辑或分布式事务。
